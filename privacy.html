Kebijakan Privasi

Terakhir diperbarui: Oktober 2026

Aplikasi Admin Panel GRRM (jalurlangitkediri.com) menggunakan Google OAuth untuk memungkinkan admin login dan mengelola konten di Blogger.

Data yang Kami Akses

Kami hanya meminta akses untuk mengelola postingan di akun Blogger milik Yayasan Jalur Langit. Kami tidak menyimpan data pribadi Anda di server kami sendiri, melainkan menggunakan token akses yang disimpan dengan aman di browser Anda.

Penggunaan Data

Data yang diakses sepenuhnya hanya digunakan untuk membuat, mengedit, dan menghapus postingan di blog Anda sesuai perintah dari panel admin.

Jika Anda memiliki pertanyaan, hubungi kami di info@grrm.id.
